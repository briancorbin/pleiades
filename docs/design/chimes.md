# Chimes — reaching the factory alerts

*How to actually turn off, quiet, or replace the 2022 Forester's own chimes.
The project's founding grievance, written down as an engineering problem.*

**Principle:** every alert in this system gets on/off, volume, and sound —
including the factory ones, once we can reach them. Default passthrough is a
choice, not a constraint. What follows is an honest map of what each route
costs, not an argument against any of them.

## Where the chimes come from

Different chimes, different sources — this is why there's no single switch:

| Chime | Generated by | Reachable how |
|---|---|---|
| Rear gate ajar / open | Combination meter (cluster buzzer) | Dealer setting (volume), cluster speaker mod, gateway spoof |
| Keyless entry / lock | Body integrated unit + external buzzer | Dealer setting (7 levels, incl. off) |
| Seatbelt | Combination meter | Cluster speaker mod; no factory setting |
| Turn signal | Combination meter (synthesized) | Cluster speaker mod |
| EyeSight / pre-collision | Head unit **and** cluster on 2022 | Head-unit volume setting; cluster mod for the rest |
| Reverse / park sensors | Body unit → rear speaker | Head-unit setting on some trims |

The recurring theme: **the sound is generated downstream of the CAN state we
can see.** Merope watching "gate is ajar" doesn't put us anywhere near the
transducer that beeps about it.

## The four routes

### 1. Dealer settings (SSM) — legitimate, limited, free

Subaru Select Monitor exposes customization for a subset: keyless beep volume
(7 levels including off), rear-gate beep, some warning volumes. This is a
service-menu write to the body unit, and it's the intended mechanism. A dealer
will usually do it while you wait.

- **Covers:** gate + keyless beeps. Not seatbelt, not EyeSight.
- **Cost:** a service visit, or an SSM-compatible cable + software.
- **Risk:** effectively zero — it's a supported setting.

### 2. UDS writes from Merope — the "do it ourselves" version of route 1

The same settings SSM changes are UDS `WriteDataByIdentifier` calls to the
body integrated unit. With the right DIDs we could flip them from Merope.

- **Covers:** whatever SSM covers, without the dealer.
- **Cost:** finding the DIDs (sniff an SSM session, or community reverse
  engineering), plus a TX path — Merope becomes a bus writer, which is a
  deliberate departure from listen-only and needs its own design pass.
- **Risk:** real. A wrong DID/value can misconfigure or brick a module, and
  body units are not cheap. Do it with the car parked, battery healthy, and
  a known-good rollback value recorded first.

### 3. Cluster speaker interception — the total-control route

The chimes we can't reach electronically are all generated by the combination
meter's own small speaker/buzzer. Physically intercepting that gives complete
authority over *every* cluster chime at once.

Two flavors:

- **Passive:** series resistor or inline pot on the speaker feed — turns all
  cluster chimes down together. Crude, reversible, no logic.
- **Active (the interesting one):** cut the speaker feed and route it through
  a small board (Merope's third S3 has a future). Now every chime is a signal
  we can pass through, attenuate, mute, or *substitute*. Detect the factory
  waveform, decide per-chime what happens, and drive the same speaker with
  our own audio. That's the real answer to "a soundclip instead of the
  default chime" — the factory beep is the trigger, our sample is the output.

- **Covers:** everything the cluster generates — gate, seatbelt, turn signal,
  the lot. Per-chime, if we can classify the waveforms.
- **Cost:** dash disassembly, cluster removal, soldering on the meter PCB;
  classification work (each chime has a distinct frequency/cadence pattern,
  so a small FFT or envelope matcher can tell them apart); an audio out
  stage. Not reversible in five minutes.
- **Risk:** it's your dash. Warranty implications on the cluster. Nothing
  safety-critical *breaks* — the visual warnings, the ADAS itself, and the
  head-unit alerts are all untouched — but you own what you can no longer
  hear.

### 4. Gateway spoofing — the one I'd argue against on engineering grounds

Transmit CAN frames asserting "gate closed" so the cluster never chimes.

- **Covers:** whatever state-driven chimes we can convincingly fake.
- **Cost:** TX onto a live bus, contending with the real sender.
- **Risk:** this is the route with the worst failure modes, and not because
  of the chime. Every other module listening to that frame gets the lie too —
  and on a Global Platform car, gate state plausibly touches the power
  liftgate logic, interior lighting, security, and possibly the ADAS state
  machine. You'd be debugging emergent weirdness in unrelated systems. Route
  3 gets the same outcome by cutting one wire that nothing else listens to.

## Recommended sequencing

1. **Now:** Alcyone's own alert layer — done. Per-rule sound, volume, on/off,
   master switch, custom clips. Independent of everything below.
2. **After car recon (SHED-72):** we'll know which chime-trigger states are
   visible on the bus. That makes route 3's classification job easier (we can
   correlate "cluster is beeping" with "gate just opened") and tells us
   whether route 2's DIDs are worth hunting.
3. **Route 1** any time you want the gate beep quieter with zero effort.
4. **Route 3** when you want the whole thing — ideally on a bench cluster
   first if a junkyard 2022 meter is cheap, so the dash comes apart once.
5. **Route 2** if the SSM DIDs turn up in community work; it's a nice
   middle ground for the settings it covers.
